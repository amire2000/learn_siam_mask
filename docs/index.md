# Learn SiamMask

This site teaches the ideas behind SiamMask from first principles. It assumes
Python, basic NumPy and OpenCV, modern C++, and basic linear algebra.

## Goal

Understand the full SiamMask inference pipeline well enough to explain and
trace its tensors: template and search crops, feature extraction, matching,
box prediction, and mask prediction.

Start with the [roadmap](roadmap.md).
